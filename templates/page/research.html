매수/매도 계산식 blind-spot 수정

"조합 0건" 리포트 조사에서 발견. 9개 subagent 검토 + codex 교차검증 → Critical/High/Medium=0.

  • 공포 필터 — is_market_fear_by_bollinger가 항상 False 반환하던 버그 수정(밴드폭 윈도우 슬라이스).
  • RSI 표준화 — SMA→Wilder 통일, 운영·백테스트 RSI 일치.
  • 시장 프록시 — 개별종목 대신 KOSPI/대형주로 시장 공포 판정.
  • Fear-Window — 동일봉 AND → 공포 후 N일 윈도우로 위상차 흡수.
  • 매도 손절 — 20일 고점 고아규칙 제거 → 하드손절 + 장기 MA 추세손절.
  • hybrid 매도 — async/await·df·Decimal 크래시 수정.
  • 실측 검증 — acceptance 백테스트로 "조합 0→18" 재현(버그 확정).

OHLCV 저장 수정 & 코드 정리

2~3년 백테스트 데이터 확보 과정에서 발견한 저장 버그 + dead code 정리.

  • 보존정책 — 365일 하드코딩 제거, 3년+버퍼(1400일) 보존.
  • 이력 페치 — date→datetime 크래시, 청크 중복, 부분실패 갭 캐싱 수정.
  • KOSPI 지수 — 잘못된 API 계약 수정 → 실 KOSPI 지수 적재.
  • 팬텀 행 — timestamp 정규화 버그(15:00 UTC 밀림) 수정 + 정리.
  • Dead code — vulture+pyflakes+6 subagent 교차검증 → 약 −932줄 제거(오제거 codex 적발·복원).
