# 포트폴리오 사전 현금화 계획

## 목표
고점/과열 신호가 발생할 때 **전량 손절이 아니라 선제적 비중 축소로 현금 비중을 확보**한다.

## 현재 구현
- API: `GET /api/v1/strategies/portfolio-cash-plan`
- 입력:
  - `target_cash_ratio` (기본 0.30)
  - `current_cash_ratio` (선택)
- 데이터 소스:
  - 활성 추적 중인 `sell` 분석 이력
  - 각 종목에 대해 최신 `SellStrategyService.analyze_sell_signal(..., force_refresh=True)` 재분석

## 평가 로직
종목별 긴급도 점수는 아래 신호를 합산해 계산한다.
- `sell_stage`
  - `REDUCE_1` → +35
  - `REDUCE_2` → +60
  - `EXIT_ALL` → +90
- 데드크로스 → +20
- 거래량 매도 신호 → +15
- 거래량 급증(>= 1.3x) → +10
- 강한 상승 추세로 과매수 매도 차단 → -10
- 수익 10% 이상 → +10 (선제 현금화 우선)
- 손실 -5% 이하 → +10 (리스크 축소 우선)

## 액션 규칙
- `EXIT_ALL` 또는 매우 높은 점수 → 전량 현금화
- 중간 이상 점수 → 강한 비중 축소
- 낮지만 경고 존재 → 선제 비중 축소
- 경고 부족 → 보유 유지

## 활용 방식
1. 장 시작 전 `portfolio-cash-plan` 조회
2. 상위 우선순위 종목부터 현금화 실행
3. 목표 현금 비중 도달 시 신규 진입 제한
4. 장중 재분석으로 단계 상승 시 추가 감축
